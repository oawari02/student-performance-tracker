# 📚 Student Performance Tracker

A beginner-friendly **Python command-line application** for managing student performance records.

The project allows users to add student details, enter subject marks, calculate percentages, view records, search for students, delete records, and view class statistics.

This project was built as part of my **Introduction to Programming** practice to apply fundamental Python concepts in one complete application.

## ✨ Features

* Add student records
* Enter marks for Maths, Science, and Computer
* Validate marks between 0 and 100
* Calculate total marks and percentage
* Automatically classify results:

  * Distinction
  * First Class
  * Pass
  * Fail
* View all student records
* Search for a student by name
* Delete a student record
* Display class statistics
* Find the highest and lowest scorer
* Interactive menu-driven interface
